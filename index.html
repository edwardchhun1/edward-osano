Cookie Consent

This demo shows how the Osano Cookie Consent script integrates into a webpage. The banner below is rendered by the Osano script tag placed in the <head> of your site. You can trigger the banner and the preference center independently.

Implementation · HTML 
<!-- Paste this in your <head> -->
<script src="https://cmp.osano.com/YOUR_CONFIG_ID/osano.js"></script>

<!-- Trigger banner programmatically -->
<script>
  // Show cookie preferences dialog
  Osano.cm.showDrawer('osano-cm-dom-info-dialog-open');

  // Listen for consent changes
  window.addEventListener('osano_consentSaved', (e) => {
    console.log('Consent saved:', e.detail);
  });
</script>

Data Subject Access Rights

Osano DSAR embeds a privacy request form directly into your website. When a data subject submits a request, Osano automatically routes it to the right team, starts the compliance clock, and handles identity verification — all configurable from your dashboard.

Implementation · HTML 
<!-- Drop the Osano DSAR widget anywhere on your page -->
<div id="osano-dsar-widget"></div>

<script
  src="https://privacyportal.onetrust.com/embeddedRequestForm/YOUR_UUID"
  type="text/javascript"
  charset="UTF-8"
></script>

<!-- Optional: listen for submission events -->
<script>
  window.addEventListener('message', (e) => {
    if (e.data?.type === 'DSAR_SUBMITTED') {
      console.log('Request ref:', e.data.referenceId);
    }
  });
</script>
